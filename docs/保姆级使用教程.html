0野兔 v2 是什么

给测试同学和产品同学做的手机调试小工具:不用背 adb 命令、不用配环境, 插上手机点鼠标就能完成日常调试动作。支持安卓(adb)和鸿蒙(hdc), 两套工具内置在 app 里,电脑啥都不用装。

六大功能一句话说明
① 手机信息型号/系统版本/序列号/分辨率/电池…一屏看全
② 已装应用列出全部应用,搜索包名、看版本号
③ 网络信息接口地址、DNS、WiFi、当前代理
④ 全局代理一键把手机流量指到 Charles / mitmproxy(插线场景)
⑤ 安装应用双击选 apk/hap 直接装,流式显示安装输出
⑥ 配置助手电脑起一个二维码页面,手机扫码照步骤配代理(无线场景)
💡 v2 是 v1(tkinter)的 PyQt6 重写版:深色界面、线程更稳、新增命令日志 和配置助手。核心调试逻辑与 v1 完全一致,v1 位于 ../yetu。

160 秒极速上手

1

双击打开 野兔v2.app,右上角看到 adb: ✓ hdc: ✓ 说明内置工具就绪。

2

手机插线(开启 USB 调试),首次连接在手机上点「允许调试」。

3

顶部下拉框出现你的手机 → 下面六个 Tab 随便点着用。

✅ 就这三步。所有操作都记录在底部「命令日志」,出问题先看它。

2开始前 3 分钟准备(手机端设置)

安卓手机

  • 设置 → 关于手机 → 连点「版本号」7 次,开启开发者选项
  • 设置 → 系统 → 开发者选项 → 打开 USB 调试
  • 插线后手机弹「允许 USB 调试吗?」→ 勾选「一律允许」→ 确定
  • 部分手机插线后 USB 用途默认「仅充电」,拉下通知栏改成「传输文件」

鸿蒙手机(HarmonyOS)

  • 设置 → 关于手机 → 连点「软件版本」7 次开启开发者模式
  • 系统与更新 → 开发者选项 → 打开 USB 调试
  • 插线授权同上。鸿蒙可能同时出现在 adb 与 hdc 两条目里,见 §10 说明
⚠️ macOS 首次打开 app 若提示「已损坏,无法打开」:终端执行 xattr -dr com.apple.quarantine /path/to/野兔v2.app 后重开(未签名应用常规现象)。

3认识主界面

未连接设备时的样子(真实截图),编号对应下表:

1品牌栏:名称与版本号(v2.0.0 · PyQt6)
2设备下拉框:所有已连接设备;格式 序列号 [安卓/鸿蒙] (型号)
3↻ 刷新设备(快捷键 F5):重新扫描 adb + hdc 设备
4内置工具状态:adb ✓ / hdc ✓ 绿色为就绪;出现 ✗ 见急救箱
5六个功能 Tab:手机信息 / 已装应用 / 网络信息 / 全局代理 / 安装应用 / 配置助手
6命令日志:每一步操作与结果,带时间戳(可从「视图」菜单开合)
7状态栏:最新状态消息(红字 = 出错);后台任务时右侧显示 ⏳
💡 未连接设备时,手机信息页会提示「未连接设备 — 请插线并开启 USB 调试」; 插线后各 Tab 切过去会自动刷新。

4Tab① 手机信息

选好设备后自动读取,也可点「↻ 刷新信息」手动刷新:

字段干什么用
型号 / 厂商提 bug 时定位机型
系统版本 / 软件版本确认测试机刷的哪个系统包
API 级别判断兼容性(安卓 13 = API 33 等)
序列号提测/报修的唯一凭证
ABIarm64-v8a 等,决定 so 库选哪份
分辨率 / 屏幕密度UI 适配排查
电池电量长测前确认电量

某一项读取失败只显示 —,不影响其他项。

5Tab② 已装应用

  • 默认只列第三方应用(自己装的那些);取消勾选「仅第三方应用」可看系统应用
  • 「搜索」框输入包名关键字,实时过滤,右侧实时显示数量
  • 版本号对前 60 个包逐一查询(避免几百个包全查太慢),其余显示 —
  • 定位某个应用的包名后,可拿去装 patch 包 / 清数据

6Tab③ 网络信息

点「↻ 刷新网络信息」,一屏展示四段内容:

  • 接口地址:手机当前所有网卡的 IP(ip addr / ifconfig)
  • DNS / 代理属性:DNS 配置与 http_proxy 相关系统属性
  • WiFi:连接状态与信号
  • 当前全局代理:是否已被设置代理(排查「手机上不了网」第一步看这里)

7Tab④ 全局代理(插线抓包,最常用)

配合 Charles / mitmproxy 抓包,不用在手机上任何设置,点按钮直改系统代理:

1

电脑启动 Charles(默认端口 8888),确认允许局域网/本机连接。

2

野兔「全局代理」Tab:主机填电脑的局域网 IP,端口填 8888。

3

点蓝色「设置代理」→ 徽标变绿「● 192.168.x.x:8888」→ 手机流量立刻走抓包。

4

HTTPS 抓包:手机浏览器访问 chls.pro/ssl 安装证书 (安卓设置里再信任;iPhone 需到 证书信任设置 开启)。

5

抓完点「清除代理」→ 徽标回「○ (未设置)」。 「↻ 读取当前代理」随时确认设备当前状态。

⚠️ 设了代理后拔线/关 Charles 而不清除,手机会上不了网 —— 这不是坏了,回来点「清除代理」就好。
💡 插线时用本 Tab(全自动);手机走 Wi-Fi 抓包或手上没线,用 Tab⑥ 配置助手。

8Tab⑤ 安装应用(APK / HAP)

1

顶部设备下拉选对设备:装 .apk 选「安卓」条目,装 .hap 选「鸿蒙」条目。

2

点「选择文件…」选安装包 → 「已识别:安卓 APK / 鸿蒙 HAP」。

3

点「开始安装」,下方日志流式滚动输出;出现绿色「✓ 安装成功」即完成,失败会带退出码与原因。

常见失败原因 / 处理
INSTALL_FAILED_ALREADY_EXISTS已装同包名不同签名,先卸载旧版
INSTALL_FAILED_VERSION_DOWNGRADE装了比手机上更低的版本(已带 -t 允许测试包,降级仍不允许)
failed to install bundle(hap)设备条目选错了,换「鸿蒙」条目重试
一直卡在 installing手机端弹了确认框没点,或存储已满

9Tab⑥ 配置助手(扫码配代理,无线场景)

手机走 Wi-Fi 抓包、或者手上没线时用这个:电脑起一个配置页,手机扫码照做。

1

电脑启动抓包工具(Charles 8888 / mitmproxy 8080),勾选允许局域网连接。

2

野兔「配置助手」Tab:「代理端口」填抓包工具的端口,点「启动助手」→ 徽标变绿,右侧出现二维码,日志记录页面地址。

3

手机(与电脑同一 Wi-Fi)扫码打开「代理配置助手」页面。

4

页面上:点「复制完整地址」→ 按自动识别出的本机系统步骤(Android 长按 Wi-Fi 修改;iPhone 进 Wi-Fi 详情配代理)填入即可。

5

页面顶部徽标实时显示「抓包服务在线 / 未检测到」(5 秒自动刷新),确认电脑端 Charles 真的在跑。

6

抓完:手机按页面提醒把代理改回「关闭」。

两个代理 Tab 怎么选场景耗时
④ 全局代理设备已插线3 秒,全自动
⑥ 配置助手没带线 / Wi-Fi 通道抓包 / 帮同事手机配置扫码 + 手填一次(Wi-Fi 记住后免填)

10设备管理与命令日志

为什么我的手机出现两条?

鸿蒙手机可能同时支持 adb 与 hdc,所以下拉框里有两条: xxx [安卓] 和 xxx [鸿蒙]。规则很简单:

要做什么选哪条
看信息 / 装 apk / 设代理「安卓」条目(adb)
装 hap 包「鸿蒙」条目(hdc)

命令日志怎么看

[19:59:02] $ adb devices -l + hdc list targets [19:59:02] ⏎ ok [19:59:02] 配置助手已启动 http://192.168.1.32:8770/proxy

$ 开头是执行的命令,⏎ 是结果(ok / failed + 原因)。 提 bug 时把这段截图发出来,定位快得多。

11常见问题急救箱

设备下拉框是空的 / 点刷新也没设备
① 换一根能传数据的线(很多线只能充电);② 手机确认 USB 调试已开并点过「允许」; ③ 拉下通知栏把 USB 用途从「仅充电」改成「传输文件」;④ 拔插重连后按 F5。
右上角显示 adb: ✗ 或 hdc: ✗
内置工具被杀毒软件删除了。重新 bash build.sh 打包, 或检查 野兔v2.app/Contents/Resources/tools/ 下 adb / hdc 是否存在。
装 .hap 一直失败
九成是设备条目选错了:.hap 必须选「鸿蒙」条目(hdc 序列号与 adb 不同)。 换条目重装;仍失败看日志里 hdc 的具体报错。
设置代理后手机上不了网
电脑端抓包工具关了但代理还指着它。回「全局代理」Tab 点「清除代理」即可恢复。 记住口诀:谁设的代理谁清,拔线之前先清除。
Charles 抓不到 HTTPS 请求
手机没装/没信任证书:浏览器访问 chls.pro/ssl 下载安装; Android 7+ 的 App 默认不信任用户证书(属于应用自身配置);iPhone 要在 「证书信任设置」里手动开启完全信任。
配置助手「启动失败(端口被占用?)」
页面端口 8770 被占:换个端口(如 8771)再启动。 状态栏和日志会给出具体错误。
配置助手页面显示「未检测到抓包服务」
电脑上 Charles / mitmproxy 没启动,或「代理端口」填得不对(Charles 8888 / mitmproxy 8080)。 页面每 5 秒自动重测,启动抓包工具后稍等即变绿。
配置助手能给别人用吗
可以 —— 同一 Wi-Fi 下任何人扫码都能打开配置页(无鉴权),这正是「帮同事配代理」的用法; 但也意味着不要在不可信网络里长时间开着。
手机是 iPhone 能用吗
adb/hdc 是安卓/鸿蒙体系,设备信息、装包、全局代理不支持 iPhone; 但「配置助手」页面是通用网页,iPhone 可以扫码按 iOS 步骤手动配 Wi-Fi 代理。

12安全须知

  • 「全局代理 / 清除代理」「安装应用」都是写设备的敏感操作,只对测试机执行。
  • 「配置助手」页面局域网内无鉴权可开,公共网络不要长时间启动。
  • 配代理抓包会经过你电脑的网络,测试机上的账号数据可能被记录,注意合规。
  • 装 patch / 测试包前确认来源,别装来路不明的 apk。
