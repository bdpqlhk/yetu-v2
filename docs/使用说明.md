# 野兔 v2 · 使用说明

**野兔 v2** 是一个手机调试工具箱:查看安卓/鸿蒙设备信息、已装应用、网络状态,
设置全局代理,安装 APK/HAP,还带一个「配置助手」帮手机快速配抓包代理。
**自带 adb / hdc,电脑无需预装任何环境。**

---

## 一、快速开始

1. 双击打开 `野兔v2.app`(首次被拦截见 §6 常见问题)
2. 手机开启 **开发者选项 + USB 调试**,数据线连上电脑
3. 安卓首次连接:手机弹出「允许 USB 调试?」→ 勾选「一律允许」→ 确定
4. 顶部下拉框出现设备即可开始;没有就点「↻ 刷新设备」(或按 `F5`)

界面分区:

| 区域 | 说明 |
|---|---|
| 顶部品牌栏 | 版本信息 |
| 设备栏 | 设备下拉框 + 刷新;右侧 `adb ✓ hdc ✓` 表示内置工具就绪 |
| 六个 Tab | 手机信息 / 已装应用 / 网络信息 / 全局代理 / 安装应用 / 配置助手 |
| 底部命令日志 | 每步操作的时间戳记录(排查问题先看这里) |
| 状态栏 | 当前状态提示;多个操作并行时显示 ⏳ |

> 同一台鸿蒙手机可能出现**两条**(「安卓」和「鸿蒙」):
> 装 `.apk` 选安卓条目,装 `.hap` 选鸿蒙条目。

## 二、各功能使用

### ① 手机信息

选中设备后自动读取;点「↻ 刷新信息」手动刷新。
展示:型号 / 厂商 / 系统版本 / 软件版本 / API 级别 / 序列号 / ABI / 分辨率 / 屏幕密度 / 电池。
某项读不到显示 `—`,不影响其他项。

### ② 已装应用

- 默认只列**第三方应用**,取消勾选「仅第三方应用」可看全部(含系统应用)
- 搜索框输入关键字实时过滤包名
- 版本号对前 60 个包逐一查询(避免逐包 dumpsys 过慢),其余显示 `—`

### ③ 网络信息

点「↻ 刷新网络信息」,展示:接口地址(`ip addr` / `ifconfig`)、
DNS 与代理属性、WiFi 状态、当前全局代理。

### ④ 全局代理(插线场景,推荐)

配合 Charles / mitmproxy 抓包,通过 adb/hdc **直改设备代理**,全自动:

1. 电脑启动抓包工具,确认监听端口(Charles 默认 `8888`)
2. 「全局代理」Tab:主机填电脑的局域网 IP(本机 IP 可在配置助手页看到),端口填 `8888`
3. 点「设置代理」→ 状态徽标变绿即生效,手机流量立刻走抓包
4. 抓完点「清除代理」恢复直连(**重要**,否则断线后手机上不了网)
5. 「↻ 读取当前代理」可随时确认设备当前代理值

### ⑤ 安装应用

1. 顶部选好设备(装 `.hap` 选「鸿蒙」条目)
2. 点「选择文件…」选 `.apk` 或 `.hap`
3. 点「开始安装」,下方日志流式显示输出,结束给出成功/失败结论
4. 常见失败:`INSTALL_FAILED_...` 看日志末行;`.hap` 报错多半是设备条目选错

### ⑥ 配置助手(手机抓包免手输,无线场景)

给**同一 Wi-Fi 下的手机**配抓包代理 —— 不用打字,扫码照做:

**电脑端(一次性):**

1. 启动 Charles(或 mitmproxy),确认勾选允许局域网连接
   (Charles:`Proxy → macOS Proxy` 按需;Access Control 加 `0.0.0.0/0`)
2. 野兔切到「配置助手」Tab:「代理端口」填抓包工具端口(Charles `8888`,
   mitmproxy `8080`),「页面端口」保持 `8770` 即可
3. 点「启动助手」→ 徽标变「● 运行中」,右侧出现二维码

**手机端:**

1. 手机连**与电脑相同的 Wi-Fi**,相机扫码 → 自动打开「代理配置助手」页
   (也可在浏览器输入面板显示的地址)
2. 页面顶部实时显示「抓包服务在线 / 未检测到」(5 秒自动刷新)
3. 点「复制完整地址」,按页面给出的**本机系统步骤**设置代理
   - Android:设置 → WLAN → 长按当前 Wi-Fi → 修改网络 → 高级 → 代理「手动」→ 粘贴主机名和端口
   - iPhone:设置 → 无线局域网 → 点当前 Wi-Fi 的 ⓘ → 配置代理 → 手动 → 粘贴服务器和端口 → 存储
4. **HTTPS 抓包**(要看加密请求才需要):手机浏览器打开
   `chls.pro/ssl`(Charles)下载证书并安装;iPhone 还要去
   设置 → 通用 → 关于本机 → 证书信任设置 里手动开启完全信任
5. 抓完:回 Wi-Fi 设置把代理改回「关闭」;iPhone 若装了描述文件也建议删除

**与「全局代理」Tab 怎么选?**

| | 全局代理 | 配置助手 |
|---|---|---|
| 原理 | adb/hdc 直改设备代理 | 局域网页面引导手机手动设置 |
| 场景 | 设备已插线(最常用) | 没带线 / 鸿蒙 Wi-Fi 抓包 / 帮同事手机配置 |
| 花时 | 3 秒全自动 | 扫码 + 手填一次(Wi-Fi 会记住,下次免填) |

## 三、命令行工具

```bash
cd ~/tools_3/codes/yetu-v2

python3 main.py --selftest      # 自检:内置工具路径 / 面板 / 当前设备(不弹界面)
python3 main.py --smoke         # 冒烟:配置助手起服务→请求配置页→停止(验证产物用)
python3 main.py --screenshot s.png   # 无头截图(无显示环境)
bash build.sh                   # 重新打包(自动对产物跑冒烟)
```

打包产物位置:`dist/野兔v2.app`(约 85M,自带运行时与 adb/hdc)。

## 四、常见问题

| 现象 | 处理 |
|---|---|
| 设备下拉为空 | ① 换数据线(有的线只能充电)② 手机确认 USB 调试已开且已授权 ③ 拔插重试 / 点刷新;鸿蒙需确认「仅充电」弹窗选择传输文件 |
| 显示 `adb ✗` / `hdc ✗` | 内置工具被杀软误删,重新 `bash build.sh`;或检查 `野兔v2.app/Contents/Resources/tools/` |
| 打开提示「已损坏,无法打开」 | `xattr -dr com.apple.quarantine dist/野兔v2.app` 后重新打开 |
| 设置代理后手机断网 | 电脑抓包工具没开,或手机与电脑不在同一 Wi-Fi;确认后仍不行先清除代理 |
| iPhone 装了证书还是抓不到 HTTPS | 必须「证书信任设置」开启完全信任;且 App 可能走 SSL Pinning(属正常,绕不过) |
| 配置助手「启动失败(端口被占用?)」 | 页面端口 8770 被占:换一个(如 8771);或 `lsof -i :8770` 找到占用进程 |
| 配置助手状态一直是「未检测到抓包服务」 | 电脑抓包工具没启动,或代理端口填错(Charles 8888 / mitmproxy 8080) |
| 安装 `.hap` 失败 | 顶部设备下拉必须选该设备的**「鸿蒙」条目**(hdc 序列号与 adb 不同) |
| 按钮卡在「执行中…」 | 看底部命令日志最后一条;拔插设备后点刷新一般可恢复 |

## 五、面向开发者

- 源码运行:`pip3 install -r requirements.txt && python3 main.py`
- 技术细节(架构 / 线程模型 / 打包 / 已知边界):见 `docs/技术实现文档.md`
- 新增面板:继承 `PanelBase` 并加入 `yetu/gui/panels/__init__.py::PANELS`
- 更新内置 adb/hdc:替换 `tools/adb/adb`、`tools/hdc/hdc` 后重新 `bash build.sh`
